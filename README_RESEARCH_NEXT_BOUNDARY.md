# Next boundary

Experience is now permitted to influence an active cognitive state through an explicit provenance-preserving transition boundary. This is not equivalent to treating experience as truth.

The next experiment must connect the resulting state to the existing epistemic operation-selection path and use a genuinely new, structurally related problem. The observation target is whether experience-derived expectations, established knowledge, self-model information, other-agent/world-model information, and uncertainty remain distinguishable while the new problem is still subjected to epistemic tests.
