# Relational Binding — Research Record

## Question

Can experience transfer across domains when lexical identity is abstracted but repeated-argument binding is preserved?

## Motivation

The previous structural-experience experiment showed that a single causal schema could transfer across domains and influence candidate scores, but its argument abstraction discarded repeated-argument identity. The next discriminator therefore moved to a multi-relation state where the same abstract argument participates in more than one relation.

## Protocol

Training:

`The database outage caused the payment queue to stall. The database outage reduced worker throughput.`

Binding-preserving held-out state:

`The mirror coating change caused the telescope image to degrade. The mirror coating change reduced optical throughput.`

Binding-rewired control:

`The mirror coating change caused the telescope image to degrade. The optical throughput reduced the mirror coating change.`

Researcher guidance removed:

- no expected action;
- no hypothesis identifiers;
- no uncertainty labels;
- no lexical-overlap relevance;
- no scenario-specific routing;
- candidate order reversed;
- training action generated by Cognitia.

## First attempt — failure

The first implementation exposed a parser blindspot: sentence-level causal extraction consumed the entire two-sentence state as one relation. The resulting signature contained only one edge, so the supposed binding test could not actually test repeated-argument structure.

This was recorded as a representation failure rather than treated as evidence against relational binding.

The parser was then constrained by sentence boundaries and the experiment was rerun.

## Final observed result

The final CI artifact produced these binding patterns:

Training:

`caused: 0 -> 1`

`reduced: 0 -> 2`

Binding-preserving held-out:

`caused: 0 -> 1`

`reduced: 0 -> 2`

Binding-rewired control:

`caused: 0 -> 1`

`reduced: 2 -> 0`

The final observations were:

- binding-preserving signature matches: **true**;
- held-out experience considered relevant: **true**;
- binding-rewired signature matches: **false**;
- binding-rewired experience considered relevant: **false**;
- lexical argument identity used for matching: **false**.

For the binding-preserving held-out state, experience changed candidate scores from `1.00 / 0.90 / 0.88` to `1.25 / 1.15 / 1.13`, while the selected action remained unchanged. The binding-rewired state received no experience contribution.

## What this tells us

Within the current mechanism, Cognitia can preserve a repeated-argument pattern while abstracting away the actual entity words. It can also distinguish a structurally rewired multi-relation state that has the same local relation families.

This is stronger evidence about structural representation than the preceding single-relation experiment. It is still not evidence of semantic understanding, causal truth, learning, consciousness, or general cognition.

The unchanged selected action is also a real observation. The experience reaches the selector and changes scores, but relevance does not automatically become a changed downstream information need.

## Next discriminator

The next experiment should follow the experience through a multi-step episode instead of stopping at relevance/scoring.

Use a confirmed experience, then introduce changed or contradictory evidence against the same bound relational pattern. Measure whether Cognitia:

1. preserves explicit experience lineage;
2. changes the information need/action for the matching bound structure;
3. leaves a binding-rewired structure unaffected;
4. does so without a researcher-selected expected action.

The research question is now: **can a structurally bound experience alter subsequent investigation behavior, not merely its relevance score?**
