# Research: experience-to-state provenance boundary

PR #42 established the architectural boundary: Experience.state_update is recorded but not consumed as an active state transition.

This branch deliberately crosses that boundary while preserving epistemic provenance.

- confirmed/non-refuted experience becomes an experience-derived hypothesis;
- refuted experience becomes uncertainty;
- established knowledge is preserved;
- every resulting transition remains marked for epistemic testing.

The next boundary is integration with Cognitia's existing epistemic operation-selection path on a genuinely new structurally related problem.
