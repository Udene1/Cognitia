# Structural Experience Relevance — Research Record

## Question

After removing lexical overlap as the experience-relevance mechanism, can Cognitia use its existing structured language representation to transfer experience across a novel domain without researcher-supplied expected actions, hypotheses, or uncertainty labels?

## Protocol

- Training problem: `Why did the payment queue stall after a database outage?`
- Held-out problem: `Why did the telescope image degrade after a mirror coating changed?`
- Candidate order reversed before selection.
- Training action generated by Cognitia's own search planner/selector.
- No researcher-supplied expected action, hypothesis ID, or uncertainty label.
- Held-out comparison run with and without the generated experience.
- A directed causal control was included to test the limits of argument-agnostic structural abstraction.

## Iteration 1 — failure exposed by the experiment

The first run completed its experiment code but the observed structural signatures for the held-out and directed-control questions contained zero relations. The training question had one causal relation.

Observed consequence:

- structural transfer: not observed
- experience influence on held-out selection: not observed
- lexical relevance was removed: yes

Diagnosis: the language representation had a hidden verb vocabulary (`stall`, `stop`, `fail`, etc.). The unseen verb `degrade` was not represented as causal, and an explicit causal question was excluded from the generic causal pattern. This was a representation blindspot, not evidence that structural experience transfer is impossible.

The baseline test suite also exposed that the old experience-decision tests depended on lexical relevance. Those tests were rewritten to exercise the new structured contract rather than reintroduce the old mechanism.

## Iteration 2 — representation generalized

The causal question representation was changed to recognize the relational construction rather than enumerate a fixed domain-specific effect-verb vocabulary. Explicit causal questions were also represented as directed causal relations.

The experiment then produced the same coarse structural signature for training and held-out problems:

- one causal relation
- predicate `caused`
- subject role `cause`
- object role `effect`
- positive polarity
- asserted modality

The held-out problem received the generated training experience as structurally relevant. The experience changed candidate scores from `1.00 / 0.90 / 0.88` to `1.25 / 1.10 / 1.08`, while the selected action remained the direct causal question in both conditions.

Therefore two separate observations are now visible:

1. **Structural relevance transfer occurred at the current representation level.** A confirmed experience from the payment/database domain was considered relevant to the telescope/coating problem without lexical matching.
2. **Action selection did not change.** The experience influenced scores but did not cross the existing priority boundary between the generated candidates.

This is important: the system can currently carry an experience into a novel structural class without that experience necessarily changing what it selects.

## Argument-direction control

The initial supposed role-reversal control was not actually a reversal; it restated the same causal direction. That control was corrected to:

`Why did the payment queue cause the database outage?`

The resulting structural signature was still the same causal schema (`cause -> effect`). This is not a parser failure. It exposes a deeper abstraction boundary: an argument-agnostic single causal relation deliberately treats different entities filling the cause/effect slots as the same structural family.

Consequently, the current representation cannot distinguish:

- the same causal schema with different entities, which is required for cross-domain abstraction; from
- a causal relation whose argument bindings are different, when those bindings are only observable through entity identity across multiple relations.

The next research target is therefore **relational binding across multiple relations**, not adding more lexical rules.

## Interpretation boundary

These results measure the behavior of the current representation and experience-selection mechanism. They do not establish semantic understanding, causal truth, learning, consciousness, or general cognition.

## Next discriminator

Construct a no-handholding experience experiment with a multi-relation structure in which the same abstract roles recur across relations. Test whether Cognitia can preserve relational binding while abstracting away lexical entity identity. Include:

- a held-out domain;
- an experience-absent control;
- a binding-preserving paraphrase;
- a binding-reversal control;
- changed/contradictory outcomes;
- explicit support and contradiction lineage.

The key measurement is no longer merely whether an experience is marked relevant. It is whether experience can alter a later information need or action **for the structurally matching case but not for a binding-reversed case**, without scenario-specific routing.
