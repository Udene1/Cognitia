# Experiment state

PR #42 established that `Experience.state_update` is recorded but not an implemented active-state transition.

This branch deliberately crosses that boundary with provenance preserved. The capability under test is: experience may change active expectations, but cannot silently become knowledge; refuted experience remains uncertainty; resulting cognition remains subject to epistemic testing.

Do not interpret this as evidence that the complete Cognitia loop has learned yet. The next experiment must connect the resulting state to the existing epistemic path on a novel problem.
