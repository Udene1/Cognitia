# Independent Communication Consequence Experiment

## Observation

PR #48 established that a recipient consequence can reach Cognitia's existing
answer-revision boundary, but the recipient was implemented as a deterministic
test generator and Cognitia's cognitive state did not change.

The next question is narrower:

> When a recipient consequence arrives as an independent environment
> observation, what does Cognitia's existing observation machinery actually
> extract from it?

## Hypothesis

Unknown. We deliberately do not supply an interpretation rule, communication
success criterion, preferred act, expected state transition, or expected
meaning for the response.

## Experiment

Three recipient consequences enter Cognitia through the existing
`EnvironmentObservation` boundary. The existing `DocumentClaimExtractor` is
run on those observations. No communication-specific interpreter is added.

The responses are deliberately not labelled effective or ineffective. The
experiment records the claims actually extracted, including confidence,
polarity, relations, and uncertainty markers.

This is a boundary experiment, not a claim that the test fixture is a real
human recipient. The environment is independent of Cognitia's communication
selection, but its responses remain controlled research observations.

## Result

The result is generated by CI in `.ci/communication-independent-consequence.json`.
The experiment must be interpreted from that artifact rather than from whether
CI is green.

## Interpretation boundary

If the existing machinery extracts candidate claims, that demonstrates
observation/claim extraction from recipient consequences. It does not establish
that Cognitia understood the recipient's communicative intent, evaluated its own
message, or learned how to communicate.

If no claims are extracted, that is evidence that the current boundary cannot
turn this form of consequence into usable candidate evidence.

Neither result supplies a communication-learning mechanism.

## Provenance

- capability under investigation: consequence interpretation
- origin: `unknown`
- independent_of_handholding: not established by this experiment
- target adaptation: deliberately not supplied

## Next hypothesis

Only after inspecting the actual extraction result should we decide whether
Cognitia needs another experiment. We will not add an interpretation rule merely
because we expect one to be necessary.
