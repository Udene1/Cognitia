# Held-out No-Handholding v2

## Status

**Completed. The CI artifact was inspected before merge.**

## Research question

When researcher guidance is removed from the episode state, does experience generated by Cognitia itself alter later action selection on a novel problem?

## Controls removed

The experiment removed:

- expected action;
- researcher-authored hypothesis identifiers;
- researcher-authored uncertainty labels;
- scenario-specific action mappings;
- original candidate ordering as a possible positional cue.

The training action was whatever Cognitia selected from its own candidate set. The held-out problem changed domain and had no shared content-bearing terms with the training problem. A role-reversal case was also observed without assigning it a required answer.

## Observed result

The training episode generated the action `Why did the payment queue stall after a database outage?` from Cognitia's own selector.

On the held-out telescope problem, the selected action was unchanged between the experience-absent and experience-present conditions. The experience did affect the scores of the candidates, but it did not change the selected action.

The control measurement also exposed a more precise implementation limitation: the held-out problem had zero shared content-bearing terms with training, yet the current selector still considered the prior experience relevant. Its relevance calculation is based on raw token overlap and therefore treats common functional/question terms as enough to create relevance. This is not structural transfer.

## Interpretation

This is evidence that the current experience-to-action pathway can ingest an experience and alter candidate scores without producing a behavioral change on a genuinely novel problem.

It also identifies the current blindspot more sharply than the previous held-out test: **lexical relevance is standing in for experience applicability.** The selector has no representation of the causal structure that both experiences may share.

The result does not establish that Cognitia cannot transfer structurally. It establishes that the current selector does not demonstrate that capability under this no-handholding protocol.

## Research consequence

Do not patch the experiment with more keywords, special cases, or researcher-authored mappings.

The next build should replace lexical experience relevance with a structural applicability signal derived from the existing language representation: relation family, directed argument roles, and candidate status/provenance. The same no-handholding protocol should then be rerun with:

1. same structural pattern, different entities;
2. same pattern with different wording;
3. cause/effect role reversal as a negative control;
4. changed outcome evidence for the same structural pattern;
5. explicit experience lineage showing support and contradiction.

The discriminator is behavioral: prior experience should change a later action only when the current state is structurally applicable, while role-reversed or structurally unrelated states should not inherit that influence.

## Boundary

The experiment provides evidence about the current explicit experience-to-action mechanism and its lexical-relevance blindspot. It does **not** establish cognition, semantic understanding, learning, or general intelligence.
